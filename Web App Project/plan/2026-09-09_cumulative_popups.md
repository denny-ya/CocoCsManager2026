# AS 누적 실적 팝업 추가

## 반영 내용

- 경수리와 중수리의 상단 접수 누적, 완료 누적에 기존 상세 팝업을 연결했습니다.
- 중수리 상단 전월 이월에도 상세 팝업을 연결했습니다.
- 신규 버튼은 0건 또는 `-`일 때 비활성화합니다.
- 접수 누적은 기준월 1일~기준일의 정규화된 접수일을 사용합니다. 공장은 기존 작업데이터의 이관일 기준 접수일을 사용합니다.
- 완료 누적은 완료 상태이며 해당 월 1일~기준일의 수리유형별 완료일을 가진 작업입니다.
- 전월 이월은 완료 누적 중 접수일이 해당 월 1일 이전인 작업입니다. 2개월 이상 지난 접수도 포함하고, 접수일이 없으면 이월에는 포함하지 않습니다.
- 기존 집계와 같게 취소 작업도 접수 누적 날짜 조건에 해당하면 포함합니다.
- 팝업은 기존 영업점, 차대번호, 접수분류, 담당자, 소속, 접수일 등의 정보를 표시합니다. 완료 누적과 이월에는 완료일도 표시합니다.
- 기존 집계 수식, 데이터시트 구조, 엑셀 양식, 세션 및 권한은 변경하지 않았습니다.

- 경수리, 센터 중수리, 공장 중수리 각각 월초, 기준일, 기준일 이후, 이전 달·이전 두 달 접수, 접수일 누락, 취소, 완료 상태 조건을 검증했습니다.

- 실제 브라우저에서 상단 숫자와 팝업 제목의 건수, 그룹 펼침, 닫기, 0건 비활성화를 확인했습니다.
